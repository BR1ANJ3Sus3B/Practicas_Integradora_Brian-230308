# Prompt final · Business Model Canvas Interactivo

Utiliza Archify para representar la información definida por el equipo para **TI: Soporte en Acción**. No inventes funcionalidades, indicadores medidos, ingresos ni decisiones técnicas. La fuente de contenido es el README de esta práctica, transcrito y organizado a partir del encargo del equipo.

Crea una página estática HTML/CSS/JavaScript en `docs/business-model-canvas/index.html`, con exactamente siete componentes conectados: problema, usuarios, propuesta de valor, solución, procesos, tecnologías y resultados. Diferencia roles de usuarios y personajes. Muestra la brecha entre teoría y práctica y el valor de practicar TI en una simulación segura y gamificada. Adapta la interfaz a computadora, laptop, tablet y móvil, con estilo tecnológico oscuro y detalles pixel art legibles.

Identifica Unity como videojuego 2D, Flutter como consulta móvil y React / PWA como gestión y seguimiento. Incluye API, Keycloak, MongoDB, Docker, Grafana, Git, GitHub y GitHub Pages con las funciones acordadas. Respeta exclusivamente este conjunto de tecnologías.

Conserva la narrativa: Alex empieza en NovaTech Solutions; Martín es mentor, Richar se especializa en redes e infraestructura y seguridad, Marco en desarrollo; Sofía y Elena son personajes secundarios; un Saboteador interno provoca fallas.

Documenta completos los flujos del jugador, administración, contenido y autenticación, las mecánicas de XP, niveles, insignias, logros, misiones, retos, estadísticas y retroalimentación, y los beneficios esperados. Complementa el Canvas con una arquitectura interactiva usuario → Keycloak → tres aplicaciones → API → MongoDB. Relaciona jugador con Unity y Flutter, administrador/editor con React / PWA, Docker con infraestructura y Grafana con monitoreo.

Representa la cadena problema → genera → propuesta de valor → se implementa mediante → solución → necesita → recursos → permiten realizar → actividades y procesos → son utilizados por → usuarios → generando → resultados, beneficios e impacto.

Implementa hover, selección, tarjetas expandibles, modales, tooltips, conexiones y resaltado coordinado. Al seleccionar solución, destaca Unity, Flutter, React / PWA y API; al seleccionar un rol, destaca sus aplicaciones definidas. Añade navegación por teclado, cierre con Escape y movimiento reducido. Muestra la propuesta de valor destacada y ofrece su formulación completa en el detalle. Agrega una notificación ilustrativa de logro con icono, nombre y descripción genéricos, sin inventar un logro real ni copiar el diseño de otra plataforma.

Encabezado: «TI: Soporte en Acción», «Business Model Canvas Interactivo», «Proyecto Integrador». Pie: «Proyecto Integrador — TI: Soporte en Acción» y «Desarrollo y Gestión de Software».
