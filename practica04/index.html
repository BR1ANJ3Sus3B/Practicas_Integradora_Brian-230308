TI: Soporte en Acción

Business Model Canvas Interactivo

Un videojuego educativo 2D con estilo pixel art donde el jugador controla a Alex, un técnico junior recién egresado que obtiene su primera oportunidad en la empresa ficticia NovaTech Solutions y debe resolver incidentes reales de soporte, redes, programación, servidores, bases de datos y ciberseguridad… mientras descubre que existe un Saboteador interno provocando fallas de forma intencional.

    Modelo de proyecto

    Los 7 componentes

    Este Business Model Canvas no usa los 9 bloques tradicionales: representa únicamente los 7 componentes de la práctica académica. Selecciona una tarjeta para abrir su detalle y resaltar sus relaciones.

    Flujo del modelo

      Pasa el cursor sobre una tarjeta para una vista rápida. Haz clic para abrir el detalle, resaltar el bloque y sus conexiones. Pulsa Esc para cerrar.

      Solución tecnológica

      Arquitectura simplificada

      Las aplicaciones se comunican con los servicios y datos a través de una capa API. La autenticación y autorización se resuelven con Keycloak. Selecciona un nodo para resaltar sus conexiones.

      Jugador / Usuarios Estudiante · Docente · Administrador · Editor
      Keycloak Autenticación y autorización
      Unity Videojuego 2D pixel art
      Flutter Aplicación móvil
      React PWA Aplicación web
      API Capa de comunicación con servicios y datos
      MongoDB Base de datos principal

      Motivación y aprendizaje

      Gamificación y gameplay

      El proyecto usa XP, niveles, progreso, insignias, logros, misiones, retos y estadísticas. Cuando el jugador desbloquea un logro se muestra una notificación emergente inspirada en el concepto de las plataformas de videojuegos (sin copiar su diseño).

      Notificación de logro

      Demostración del concepto: notificación emergente con nombre, icono y descripción.

      Universo del videojuego

      Personajes de la historia

      Los personajes pertenecen a la narrativa del videojuego y no deben confundirse con los roles de usuario de la plataforma. La historia transcurre en la empresa ficticia NovaTech Solutions.
